# ☝🏻 Git 규칙
: Git을 난이도 높게 사용하지 않습니다. 그날 코드가 있으면 코드를 올리는 용도로 사용될 겁니다. 두려워하지 않으셔도되요 😁

1. 올가니제이션(organization)에 들어오면 개인별 레포지토리(Repository)를 생성해주세요~
   - 알아보기 쉽게 자신의 영어 닉네임으로 레포를 생성하세요
   - 생성하는 레포는 프라이빗(private)으로 해주세요
      - 모두가 올가니제이션의 오너(owner) 권한을 드립니다!
   - ‼️<b> 절대로 자신의 레포가 아니면 건들지 말아주세요! </b>

2. 자신이 생성한 레포를 자신의 컴퓨터에 클론(dlone)을 해주시면 됩니다

3. 다음에는 자유롭게 자신의 레포에 그날 복습 내용과 코드를 푸쉬(push) 해주시면 됩니다~

<br>

# ✏️ 노트는 어떤 것을 작성하면 되나요?
- 형식: 자유!
- 꼭 들어가야하는 내용: 날짜, 주제, **키워드 3개이상**, 수업 내용 정리(간단해도되요), (코드 소스파일 - 있으면), **그날 수업으로 나올만한 문제 3개 만들기**
- 노트 Template 위치: .github/noteTemplate/

<br>

# ✌🏻 스터디는 이렇게 진행하고 싶어요

1. 수업 동안 열심히 노트를 필기해주세요 (쉬는 시간도 활용 가능)
   - 노트는 자유형식이나 git에 올릴 수 있는 text 파일이나 md 파일을 추천합니다
     - 노션(Notion)이나 다른 것들도 괜찮은데 git에 올리기엔 조금 어려워요~ 🥲
     - 노션을 사용하시고 있다면 수업이 마무리 될 때 **pdf**로 추출해서 git에 올릴 수 있습니다!

2. 그날 수업이 끝나면 10분 동안만 할애해서 같이 복습해요
   - 그날 배운 내용을 **3개 이상** 키워드들을 서로 나눕니다
   - 각 키워드들을 가지고 얘기를 나눕니다
   - 무겁게 공부하는 느낌 보다 그날 배운 내용을 가볍게 되새기는게 목표입니다
     - 무겁게 공부는 혼자서~
   - 이후에는 자유롭게 😊
     - 수업 도중 막힌 부분(따라가기 어려웠던 부분)을 공유하여 같이 해결합니다
     - 질문을 공유하며 같이 답해봅니다
     - 일정이 있으신 사람은 노트만 레포에 푸쉬해주시고 그날 스터디는 빠지셔도 됩니다~ 😁
